# 基础规则：
** 1.总是在代码中添加中文注释，注释要求标注函数、类等对象的功能 **
 2.变量要求命名清晰，采用驼峰命名法，用注释标明变量的含义
 3.代码结构要求清晰，段与段之间增加空行
 4.代码符合ES6、HTML5、CSS3语法规范
 5.禁止生成与项目需求无关的代码
 6.不要打开或阅读与每次对话prompt无关的文件
# 项目要求：
## 项目描述：本实验最终交付的地图、天气AI助手：
(1)使用HTML + CSS + JavaScript进行纯前端开发
(2)用一个README.txt文件存储用到的api key，并添加使用说明，在代码中请使用占位符替换，禁止出现api key的硬编码
## 基本功能要求：
(1)嵌入高德地图，用户可以在地图上点击选择地点，显示地名和经纬度 
(2)根据选中地点的经纬度，自动调用天气 API 获取并展示当前天气信息（温度、天气状况、风速等） |
(3)在页面中提供聊天区域，用户可以基于当前选中地点和天气，与 AI 进行对话
